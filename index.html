ACTIVIDAD AUTÓNOMA: Auditoría de Migración Corporativa

Problema a resolver

La empresa cuenta con 500 equipos y se ha decidido migrar el departamento de desarrollo, compuesto por 100 equipos, desde Windows hacia Ubuntu Linux.

1. Requisitos de Hardware

Antes de realizar la migración se debe comprobar que los equipos cumplan con los requisitos necesarios para instalar y utilizar Ubuntu Linux.

Componente Requisito recomendado
Procesador Intel Core i3 o AMD Ryzen 3 como mínimo
Memoria RAM 8 GB como mínimo y 16 GB recomendado para desarrollo
Almacenamiento SSD de 128 GB o mayor
Espacio disponible Al menos 30 GB para Ubuntu y aplicaciones
Tarjeta gráfica Compatible con Ubuntu Linux
Red Wi-Fi compatible
UEFI Recomendado para equipos modernos

2. Migración de NTFS a ext4

Windows utiliza normalmente el sistema de archivos NTFS, mientras que Ubuntu puede utilizar ext4 como sistema de archivos principal.

Para realizar la migración correctamente se debe realizar primero una copia de seguridad de los archivos. Después se instala Ubuntu utilizando ext4 y finalmente se restauran los archivos.

Proceso de migración

1. Realizar un inventario de los archivos importantes.

2. Verificar que la copia de seguridad funcione correctamente.

3. Instalar Ubuntu Linux y crear las particiones utilizando ext4.

4. Restaurar los archivos de los usuarios desde la copia de seguridad.

Es importante recordar que no se debe formatear una partición NTFS sin realizar previamente una copia de seguridad, ya que el formateo puede eliminar los archivos almacenados.

3. Estructura de Particionamiento Recomendada

Para los equipos del departamento de desarrollo se recomienda utilizar las particiones raíz, home y swap.

Partición Tamaño aproximado Sistema de archivos Función
/ 50 GB ext4 Sistema operativo y programas
/home 200 GB ext4 Archivos y configuraciones de los usuarios
swap 6 GB swap Memoria de intercambio

Partición /

La partición es raíz contiene el sistema operativo Ubuntu, los programas instalados y los archivos principales del sistema.

Partición /home

La partición home contiene los archivos personales, documentos, proyectos y configuraciones de los usuarios.

Partición swap

La partición swap funciona como espacio de intercambio cuando la memoria RAM disponible no es suficiente.

4. Plan de Migración de los 100 Equipos

Fase Actividad
1. Auditoría Revisar hardware, nos ayudará en el almacenamiento, RAM, aplicaciones y archivos de los equipos.
2. Equipo piloto Migrar un pequeño grupo de equipos para realizar pruebas.
3. Respaldo Realizar copias de seguridad de los datos de los usuarios.
4. Instalación Instalar Ubuntu Linux y configurar las particiones.
5. Restauración Restaurar los archivos y proyectos de los usuarios.
6. Pruebas Comprobar Internet, programas, archivos, servidores y dispositivos.
7. Puesta en producción Entregar el equipo al usuario y continuar con la migración.

5. Conclusión

La migración de los 100 equipos de Windows a Ubuntu Linux debe realizarse de forma organizada y segura. Primero se debe comprobar el hardware, realizar copias de seguridad y posteriormente instalar Ubuntu utilizando ext4.

La utilización de las particiones /, /home y swap permite organizar adecuadamente el sistema operativo, los archivos de los usuarios y la memoria de intercambio.

Finalmente, realizar la migración por fases y comenzar con un grupo piloto permite detectar problemas antes de realizar la migración de todos los equipos del departamento.
